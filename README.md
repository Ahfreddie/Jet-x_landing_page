# Jet-x_landing_page
A simple layout landing page  for a fictional product for practicing CSS Flexbox. 
A lot of the initial content is currently just placeholder content.

## Features
- Flexbox 
- Navigation bar
- Clean and simple layout
- Accessible

## Requirements
- Font: Roboto 
- Dark background color (header, hero section and footer): #1F2937
- Logo text:
  - Font: Quicksand
  - Font size: 24px
  - Color: #F9FAF8
- Hero section main text:
  - Font size: 48px
  - Color: #F9FAF8
  - Weight: 900
- Hero secondary text and header links:
  - Font size: 18px
  - Color: #E5E7EB
- Button and CTA background color: #3882F6
- Information heading:
  - Font size: 36px
  - Color: #1F2937
  - Weight: 900
- Quote:
  - Background color: #E5E7EB
  - Font size: 36px
  - Color: #1F2937
  - Weight: 300
  - Font style: italic

## Stack
- HTML
- CSS 

## Installation

1. Download or clone the repository
2. Open project folder
3. Open `index.html` in your browser

## What I have learned
<!-- Lessons will be added here -->
- It is more efficient to work section by section instead of try to work on a lot of things simultaneously
- Working section by section makes it easy to spot errors.
- Flexbox is way more powerful, even though in this project I didn't utilize it fully, I have learnt how wonderful it can used for layout without grid.
